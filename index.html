Publicando

Do computador pro ar em quatro pedidos.

  1. "Cria um repositório no GitHub com esse projeto e sobe os arquivos." Como você já entrou no GitHub na aula de configuração, ele faz e te mostra o link.

Se o passo anterior travar

Caminho B: publicar pelo site do GitHub. Seis cliques, igual no Mac e no Windows.

  1. Em github.com, botão New repository. Nome, Public, criar.
  2. Na tela do repositório vazio: uploading an existing file.
  3. Arrasta os arquivos da pasta e clica em Commit changes.
  4. Menu Settings, depois Pages.
  5. Source: Deploy from a branch · main · / (root). Salva.
  6. Espera 2 minutos e recarrega. O endereço aparece nessa mesma tela.

Supabase

O Supabase é o Google Drive das informações do seu site.

Você já usa o Drive pra guardar os vídeos que manda pra marca. O Supabase é a mesma ideia: uma pasta na internet. A diferença é que quem guarda e busca as coisas lá dentro é o seu site, sozinho.

O que fica guardado lá

Seu loginSeus vídeosSeus contatos de marcaSeu calendárioSuas campanhas

Cada coisa que você salva vira uma linha lá dentro. Quem cria essas pastas e organiza tudo é o Claude, sozinho. De você, ele só precisa que a conta esteja criada.
